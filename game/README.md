# game/

Весь новый код живёт здесь. Старый код остаётся в `scenes/`, `world/` и переезжает в `legacy/` по мере разбора.

## Правила

- `core/` — чистые классы (RefCounted), без нод и без сцены. Тестируются headless.
- Системы общаются через `LkGameEvents` (сигналы), а не прямыми ссылками друг на друга.
- Состояние хранится в явных автоматах (`LkPlayerMode`, `LkTerrainSession`), а не в наборах булевых флагов.
- Наследование от тестовых сцен запрещено. Переиспользование — через композицию.
- UI только читает состояние. Debug можно удалить без последствий для игры.
- Не больше одного автозагрузчика (autoload) без веской причины.

## Структура

```
game/
  game.tscn, game.gd   корень композиции (LkGame)
  core/                автоматы состояний, события
  world/               тела, каталог, часы, transfer      (будет)
  terrain/             host, stream, reanchor, edit       (будет)
  player/              режимы движения, contact, recovery (будет)
  ui/                  HUD, меню                          (будет)
  debug/               perf, flight cpu, навигация        (будет)
```
